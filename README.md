## 📑 Deliverables Index & Summary

### 1. Requirements Documentation
Defines the foundational behaviors and constraints for the course project:
* **Functional Requirements (FR):** Core operational features, authentication logic, and domain rules.
* **Non-Functional Requirements (NFR):** Performance criteria (<2s response time), security, usability, and scalability.

### 2. User Stories & Acceptance Criteria
User stories written across key application roles (*End-user, Admin, Manager*) using standard agile syntax:
> *As a [role], I want to [action] so that [benefit].*

Paired with acceptance criteria structured in **Gherkin notation** (*Given / When / Then*).

### 3. User Story Mapping & Release Planning
Visual layout prioritizing backlog user stories by activity flows and project iterations:
* **Release 1 (MVP)**
* **Release 2**
* **Future Iterations**
